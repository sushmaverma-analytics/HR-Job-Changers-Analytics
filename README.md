# HR-Job-Changers-Analytics
HR Analytics Dashboard built using Power BI and DAX
## 📌 Project Overview
This project analyzes HR candidate data to identify patterns influencing job change behavior using Power BI.


## 🎯 Objective
To analyze candidate data and understand:
- Which candidates are more likely to change jobs
- Impact of experience on job mobility
- Company size influence
- Education level impact
- City development index role

---

## 🏗️ Data Preparation
- Cleaned data in Power Query
- Handled null values
- Converted data types
- Created Experience Group column
- Built DAX measures for KPIs

---

## 📊 KPIs Created
- Total Candidates
- Job Changers
- Job Changers %
- Active Candidates
- Avg Experience
- Avg Training Hours
